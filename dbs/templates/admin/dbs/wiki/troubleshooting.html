Troubleshooting

"Credential cannot be read with the current SECRET_KEY"

The target's stored secret was encrypted under a different key. Add the old key to SECRET_KEY_FALLBACKS, or re-enter the credential.

The panel logged me out

Run python manage.py dbs security unlock USERNAME, then add your network to the trusted list in setup.

A restore merged when I wanted it to replace

Tick Replace instead of merge, or pass --flush on the command line.

"The backup holds data for models this project does not have"

The backup comes from code with apps or models this project lacks. Install them, or deploy the code the backup was taken from. To restore the rest without them, tick Allow missing models, or pass --allow-missing-models.

A restore failed with "Nothing was changed"

The database refused a row; the message names it. When it says the restore was merging, the rows already here hold the same data under other ids: Replace instead of merge loads the backup over them.

The scheduler will not start

It needs an output directory: pass --output-dir or set DBS_BACKUP_DIR.

django_dbs is not recognized / command not found

pip installed the script into a folder that is not on your PATH, common with Windows user installs and pip install --user; pip prints that folder in a warning during the install. Add it to PATH, or run python -m dbs.manager run instead. dbs-client works the same way as python -m dbs.client.
