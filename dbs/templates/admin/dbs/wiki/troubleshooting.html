Troubleshooting

The panel logged me out

Run python manage.py dbs security unlock USERNAME, then add your network to the trusted list in setup.

A restore merged when I wanted it to replace

Tick Replace instead of merge, or pass --flush on the command line.

A backup refuses its output path

dbs backup never replaces a file. Choose a new name each run, or let the schedule name them.

A backup stops on files it cannot read

It names each missing or unreadable source file. Restore them, or pass --allow-missing-files to back up without them.

A restore refuses a file

Files land only inside the restore roots. Add the directory to DBS_RESTORE_ROOTS, or map the old root to a new one with DBS_RESTORE_PATH_MAP. A dry run lists every file it would refuse.

The scheduler will not start

It needs an output directory: pass --output-dir or set DBS_BACKUP_DIR.

A panel backup stops with time_limit, memory_limit or killed

Panel backups and restores run in a process of their own. Raise DBS_JOB_TIME_LIMIT (6 hours by default) or DBS_JOB_MEMORY_LIMIT (2 GiB, 0 for none); killed means the process ended without a word, often the system's memory killer. Behind uWSGI or mod_wsgi, set DBS_JOB_PYTHON to the project's Python. python manage.py dbs upgrade checks that the process can start.

A backup fails with disk_full, permission_denied or read_only

DBS_BACKUP_DIR is full, not writable by the user the project runs as, or on a read-only mount. Older backups there are untouched.

django_dbs is not recognized / command not found

pip installed the script into a folder that is not on your PATH, common with Windows user installs and pip install --user; pip prints that folder in a warning during the install. Add it to PATH, or run python -m dbs.manager run instead.
