The DBS manager

The DBS manager is a separate application in the same package. Run it on your own machine with:

django_dbs run

If the shell says django_dbs is not recognized, pip put the script in a folder that is not on your PATH. Run python -m dbs.manager run instead, or install with pipx install django-dbs.

It opens in your browser and looks after many servers over SSH: it takes and pulls their backups, keeps their .env versions and folder archives, and can restore a project onto a new server when the old one goes down.

Letting it reach this project

  1. Open Connection and press Copy.
  2. In the manager, choose Add a server and paste the snippet. Without one, the manager searches the server for the project once it can sign in, and Browse the server lets you pick its folder from the server's own folders.
  3. Confirm the host key fingerprint matches the one shown on the Connection page.
  4. Add the key the manager shows to ~/.ssh/authorized_keys for the user that owns this project.

This project never contacts the manager and keeps nothing about it. A backup the manager asks for is written to DBS_BACKUP_DIR and recorded in the audit trail like any other backup.
